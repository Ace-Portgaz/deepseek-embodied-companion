# 版本与验证

当前同步手机组件 **v42 / 0.6.1-dafeiyu-touch**。基础 ROM 是此前完成硬件修复的 LineageOS 18.1；后续同签名组件更新加入中文大肥鱼、全身模型、视觉、语音和点击互动。旧 ROM 产物不会自动包含新组件。

## 已完成的真机验收

| 阶段 | 已确认结果 |
| --- | --- |
| 系统启动 | HOME 正常，Trebuchet 崩溃已修复 |
| 硬件 | 录音回放正常，前后摄像头可用，持久修复经重启复核 |
| 视觉 | 眼神方向正确；点头、摇头、挥手与距离变化可识别 |
| 中文迁移 | 全身比例、眼神、脸部渲染正常；花火中文音色和嘴型正常 |
| 事件对话 | DeepSeek 能参考最近挥手事件回答 |
| 点击互动 | 点击头发／尾巴先做动作，再用中文声音回应，部位对应 |
| 作者表现 | 维护菜单中脸红、爱心眼、抚胸手有明显变化 |

这些是单台 lavender 的用户验收记录，不表示所有设备和素材都兼容。相机识别受光线、遮挡、距离和设备负载影响。

## 公开离线验证

运行 `bash scripts/test-offline.sh`，与 GitHub Actions 使用同一入口：

- 云端配置、设备认证、身份隔离、语言分支、视觉事件过滤、ASR 结束帧、合成回退与额度账本。
- 刷机门禁、手机状态与观察策略、触摸冷却及忙碌状态。
- 中文文本前端与语音服务边界，模拟推理，不加载私人权重。
- 视觉参数、曲线采样、网格命中顺序、表情叠加、动作回收和嘴型优先级；使用合成模型数据。
- 资产导入路径校验、公开文件大小／后缀／敏感信息模式、Python 语法与文档本地链接。

测试不访问付费 API，不刷手机，不运行摄像头，也不证明外部模型文件完整。训练、真实推理、完整 Android 构建、资源效果和端到端语音仍需独立验收。
