# 故障记录与排查

| 现象 | 本工程原因 | 处理与验证 |
| --- | --- | --- |
| ESP32 重复重启 | 清理配置破坏旧固件兼容字段 | 恢复备份，保留相关字段，回读 NVS 与服务端收音确认 |
| 能连接但没回答 | 测试语音额度已触发保护 | 查看持久账本，在明确额度后更新限制，保留已用量 |
| 源码下载不动 | 网络失败、临时文件无增长或低空间暂停 | 检查守护状态和 Git 进程；不删除已下载对象 |
| C 盘持续变小 | 系统/WSL/临时文件和宿主资源占用 | 同时监测 C、D；守护脚本保留 C 8 GiB、D 35 GiB 停止阈值 |
| 编译 78% 报错 | QTI 蓝牙头文件路径缺失 | 仅修 include 路径，继续增量构建 |
| 重试从 31% 开始 | Ninja 本轮剩余任务分母发生变化 | 比较任务与产物，不能用百分比推断全部重编 |
| 刷 Recovery 后又回 MIUI | 恢复环境没有真正进入或启动失败 | USB/启动键/Recovery 标题逐项确认，再校验 DTBO 与镜像批次 |
| `Trebuchet keeps stopping` | 自定义 HOME 后 Quickstep 假设失效 | 空 HOME 处理、RecentsActivity 回退，重启确认初始化无弹窗 |
| 后置相机黑屏 | XML 引用了不存在的 HFR tuning 库 | 成对配置与库校验；临时验证后制作持久 OTA，再重启验证 |
| 前摄像头无法打开 | 初版只有后摄像头检查入口 | 增加前置 Camera2 入口并校正方向/比例 |
| 能识别摇头，不能挥手 | 手势门限只覆盖部分摆动轨迹 | open palm + 手掌/手腕时序摆动，真实挥手复测 |
| 手机“网络错误” | websockets 14.2 不接受新的 proxy 参数 | 兼容传输构造，先短句 ASR，再端到端测试 |
| 能对话却不提挥手 | 事件表达和当前轮提示优先级不足 | 对应语种的具体动作 + 相对时间，优先当前轮事件 |
| CPU 音色太慢、内存过大 | 原始 PyTorch 和参考编码器常驻 | ONNX 转换、参考特征预计算、外部权重直接加载 |

## 建议排查顺序

1. **硬件**：维护菜单录音回放、前后相机、方向与比例，避免云端掩盖本地问题。
2. **网络与身份**：手机 Wi-Fi、服务器 TLS、设备 status；未授权请求必须继续被拒绝。
3. **额度**：持久账本是否存在、当天用量、paused；不要通过删文件“重置”。
4. **识别**：确认录音格式及最终 ASR 文本，临时结果不应触发回答。
5. **对话**：模型名称、API 错误、近期事件是否随当前请求抵达。
6. **合成与播放**：Unix socket、服务负载、有效 PCM、回退路径、手机音量与嘴型。

收集日志时只记录阶段、错误类别和耗时。不要公开完整 Authorization、初始化 URL、请求音频、私人人设或记忆。当前离线测试不需要真实凭据；复现错误时优先使用模拟输入。

完整 ROM 不能正常开机时，先保留 Recovery，核对产品与镜像；未定位问题前不要反复格式化或把其他机型文件拼进当前镜像。当前项目中的修复基于固定 lavender 源码与厂商文件。

## 中文大肥鱼阶段

| 现象 | 处理 |
| --- | --- |
| 日语参考音色说中文有口音 | 改用中文素材微调 GPT 和 SoVITS，重新试听；仅修改语种参数不足以保证自然声调 |
| 中文声调／韵律不对 | 检查中文 G2P 与 BERT 对齐，导出正确倒数第三层特征，不使用全零特征替代 |
| 偶尔变成另一种女声 | 查看实际 engine/profile 和错误阶段；克隆失败会回退火山，并非换了私人记忆 |
| 个别短句生成空音频 | 规范语气词、修复空分句，提前 EOS 时有限重试；仍共享 25 秒截止时间 |
| 全身贴图黑块或脸部黑色 | 核对 GPU 最大纹理尺寸、Multiply/Screen Color 兼容和模型入口，不修改原始素材 |
| 模型一直只有一种表情 | 原 model3 未注册作者资源；生成 interaction sidecar，检查动作是否覆盖了捕捉参数 |
| 点透明背景也触发 | 使用变形三角网格、显示顺序和纹理透明度过滤，不只判断矩形范围 |
| 点击没有语音 | 检查互动开关、8 秒冷却、当前是否忙碌、网络与日额度；后台与长按不会发起对话 |
| 显示今日额度用完 | 检查 429 与持久账本；如增加当天额度，保持原计数和次日常规上限 |
