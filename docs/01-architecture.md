# 架构与职责

手机是感官和表现终端，DeepSeek 是对话服务。二者之间传递有限的语音、文本和动作事件，不把每一帧图片交给大模型。

| 层 | 位置 | 职责 |
| --- | --- | --- |
| 系统与驱动 | 手机 | LineageOS、Camera2、麦克风、扬声器、系统 HOME |
| 本地观察 | 手机 | MediaPipe 脸部与手势推理，时序动作判断，目标丢失回正 |
| 角色表现 | 手机 | 全身 Live2D、作者表情与动作、眼神、嘴型、点击部位判定 |
| 对话 | 云端 | 火山中文 ASR、DeepSeek、人格提示词、近期视觉事件、摘要记忆 |
| 音色 | 云端 | 中文微调 GPT-SoVITS 的 ONNX 推理；私有 Unix socket |
| 访问控制 | 两端 | 手机独立 token、固定 HTTPS 主机、服务端设备白名单 |

视觉反馈即时在手机执行；不等待 DeepSeek 返回才移动眼睛。点头、摇头、挥手等进入最近事件缓冲，在下一轮对话时提供给模型。点击模型先触发本地表情和手势，再发送明确的“屏幕点击某部位”文本事件。回复中的关键词可影响本地表情；当前没有让 DeepSeek 自由执行系统命令或直接控制摄像头。

手机、ESP32 使用独立设备凭据，通过服务端管理员配置的别名共用一份摘要记忆。换设备不会自动获得旧记忆权限；正确登记后可延续偏好与经历，不需要复制一个容易分叉的记忆文件。

角色名为大肥鱼，内部 `Rem*` 类名、目录、systemd 服务、环境变量和接口保留兼容。项目更名不会触发数据清空、签名更换或手机重刷。部署用例是单用户实验系统，并非通用多租户平台。
