# 数据流、公开范围与外部资源

## 数据去向

| 数据 | 去向与处理 |
| --- | --- |
| 摄像头帧 | 手机本地视觉管线；当前实现不保存、不上传 |
| 动作 | 有限事件及相对时间，随本轮对话送到自有服务器 / DeepSeek |
| 用户录音 | 通过自有服务器交给火山 ASR；当前应用不提供录像档案 |
| 文本、人设、相关记忆 | DeepSeek 对话 API；服务端保存有限摘要和人设 |
| 回答文本 | 优先自有 Genie 进程；回退时交给火山 TTS |
| API 密钥 | 本机私密配置、自有服务器私密配置；不进入手机、模型资产或仓库 |
| 手机 token | 手机私密存储；服务端登记 hash |

服务供应商对数据的处理规则需自行核对其现行政策。本地处理摄像头不意味着整个系统离线；语音识别和对话仍是云端服务。

## 公开仓库包含

- 自定义手机组件、视觉策略、渲染桥与非资产控制代码。
- 云端适配、手机接口、额度、记忆和 TTS 工作进程。
- 固定版本记录、公开上游链接、配置模板、关键系统补丁。
- 离线测试、复现文档、历史故障与验收摘要。

## 不包含

- 实际 IP、MAC、手机序列号、设备凭据、登录 Cookie、API key、SSH 管理密钥。
- 私人聊天、记忆文件、录音、相机帧、截图和原始排错日志。
- 用户提供的角色 ZIP、Live2D 模型/纹理、原始视频、参考人声、生成试听。
- 厂商二进制、完整 ROM、Recovery、模型权重、第三方 SDK 二进制、虚拟环境。

`.gitignore` 防止常见误加；`scripts/check-public-tree.py` 检查实际 Git 追踪文件。被忽略不代表已从历史删除；如果曾推送真实凭据，必须先撤销凭据，再处理历史。报告问题时提供经过脱敏的错误类别和复现步骤。

## 外部资源清单

| 资源 | 准备方式 |
| --- | --- |
| Android/Lineage 源码 | 设备清单与解析后的 manifest；按对应上游取得 |
| lavender 厂商文件 | 原厂/合法上游来源，对照固定 proprietary lists 验证 |
| Live2D 形象及 SDK | 自备许可允许的资源；使用补齐工具或按渲染路径适配 |
| MediaPipe Java/JNI/任务模型 | 官方下载脚本与许可归档 |
| GPT-SoVITS 权重 | 固定 revision + manifest 校验下载器 |
| Genie 模板和编码器资源 | 固定来源记录，转换前重新核对 |
| 参考音频与转写 | 自行准备，保存在忽略目录 |
| 火山 / DeepSeek / TLS | 自有账号、凭据与可用套餐，不能靠复制示例获得 |

本仓库不提供一键下载角色录音，也不把参考声音、厂商文件或 Live2D 专有部分重新许可。
