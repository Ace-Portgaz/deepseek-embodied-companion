# 数据流与外部资产

## 什么会离开设备

| 数据 | 去向 |
| --- | --- |
| 摄像头原始帧与关键点 | 手机本地处理，不持久保存或上传 |
| 最近点头／摇头／挥手等事件 | 下一轮请求时发到自己的服务器，再作为文字上下文提供给 DeepSeek |
| 屏幕点击部位 | 作为明确的屏幕交互文字发到云端，不开启麦克风 |
| 按钮录音 | 自有服务器 → 火山 ASR |
| 识别文本、当前人设、相关摘要 | 自有服务器 → DeepSeek |
| 回复文字 | 私有 Genie 推理；失败回退时提交火山 TTS |
| 偏好和经历摘要 | 自有服务器持久保存，设备间通过身份别名共享 |

手机仅持有独立设备 token；DeepSeek 和火山密钥留在云端私密配置。HTTPS 固定主机，不能为排错关闭证书验证。记忆是摘要，不是完整逐字历史。停用或遗失设备应撤销其独立凭据。

## 不公开的内容

API 密钥、设备凭据、云服务器实际地址、账号资料、私人记忆和日志；原视频／录音、训练数据、参考文本配对、训练和 ONNX 权重；Live2D 模型、贴图、动作资源及 PSD；签名密钥、手机备份、完整 ROM、厂商二进制和本机校验收据。

`.gitignore` 屏蔽这些目录与文件，`scripts/check-public-tree.py` 检查 Git 跟踪文件。发布前还应检查 staged diff；忽略规则不能自动清除以前提交过的秘密。

## 自行准备的资源

模型请从 [Kamiya_Ryoko 的主页](https://vgen.co/KAMIYA) 查找原始发布并遵守原包条款；本项目不重新分发模型。声音素材来源鸣谢 [AI Hobbyist 资源库](https://res.acgnai.top/)，使用时分别核对具体素材的许可。来源链接不等于授予素材再分发或商业授权。

Live2D Cubism Core、MediaPipe 模型、GPT-SoVITS 预训练权重、中文 BERT、Genie 转换依赖和 Android 厂商文件需另行准备。代码仓库可以先运行离线测试；不承诺下载后直接得到完整可刷镜像或可用音色。
